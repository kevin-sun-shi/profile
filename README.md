## 🚀 Live Demo / 如何在 GitHub 上访问完整网站

GitHub 仓库页面（`github.com/kevin-sun-shi/profile`）是用来存放项目**源代码**的。
若要在网页中查看实际渲染出的效果：

1. **直接访问已部署的网页（GitHub Pages）**：
   👉 **[https://kevin-sun-shi.github.io/profile/](https://kevin-sun-shi.github.io/profile/)**

2. **开启 GitHub Pages 步骤**：
   - 点击本仓库顶部的 **Settings** ⚙️；
   - 在左侧点击 **Pages**；
   - 在 **Build and deployment** 下方的 **Source** 选择 **GitHub Actions**；
   - 等待 Actions 部署完成后即可通过上方链接访问！

## 💻 Local Development / 本地运行

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器
npm run dev

# 3. 打包生产版本
npm run build
```

## 🛠 Tech Stack / 技术架构

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 (Dark mode obsidian aesthetics)
- **Audio Engine**: Native Web Audio API + Real-time Canvas FFT Spectrum Visualizer
- **Icons**: Lucide Icons
- **Deployment**: GitHub Actions + GitHub Pages
